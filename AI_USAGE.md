# AI Usage

AI tools were used as a supporting resource during the development of this project.

---

## Purpose of AI Usage

Since some parts of the project involved new concepts (such as Laravel architecture patterns and deployment workflows), AI was used to:

- Clarify concepts and understand best practices
- Assist in debugging errors and resolving issues
- Explore different implementation approaches
- Improve UI/UX design ideas

---

## Nature of Usage

- AI was primarily used for **learning and guidance**
- All code was **written, tested, and modified manually**
- Suggestions were carefully reviewed before applying
- Final implementation reflects personal understanding and decisions

---

## Examples of Assistance

- Understanding how to structure a modular quiz system
- Debugging API and database-related issues
- Learning deployment steps and environment setup
- Improving frontend interactions and validation

---

## Final Note

AI acted as a **learning assistant and debugging aid**, helping accelerate development while ensuring that the final solution was fully understood and implemented independently.
